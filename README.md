# مؤسسة أبو سبعة لتحلية المياه — الموقع

## المكونات
- صفحة هبوط عربية RTL متجاوبة للجوال واللابتوب.
- CTA مباشر لواتساب واتصال هاتفي.
- نموذج طلب عرض سعر يجهز الرسالة تلقائيًا لواتساب.
- صفحة سياسة الخصوصية.
- `sitemap.xml` و`robots.txt`.
- Meta title/description + Open Graph + Twitter Card.
- Schema.org لـ LocalBusiness وWebSite وFAQPage وخدمات المؤسسة.
- أحداث تحويل جاهزة للربط مع Google Ads / Google Analytics عبر `gtag` عند إضافة IDs الحقيقية.
- شريط إجراءات ثابت للجوال + زر واتساب ظاهر داخل الـHero للجوال.

## قبل الإطلاق
1. تأكد من النطاق النهائي والدومين الموجود داخل `canonical`, `og:url`, `sitemap.xml`, `robots.txt`.
2. اربط Google Ads/Analytics وأضف Conversion IDs الحقيقية إلى نظام التتبع الذي تستخدمه.
3. راجع البريد الإلكتروني ورقم الجوال والعنوان الفعلي إن تغيرت عن البيانات الحالية.
4. ارفع مجلد المشروع كما هو إلى الاستضافة.

> ملاحظة: التصميم وتهيئة التحويلات جاهزان، لكن لا يمكنني ضمان موافقة Google Ads أو ترتيب Google؛ ذلك يعتمد على إعدادات الحساب، الصفحة المقصودة، الإعلان، وسياسات Google.
